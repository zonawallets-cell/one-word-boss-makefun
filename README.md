One word for the boss: **Arsonist**. The boss who starts the fires, then
gets praised for putting them out.

`main.py` (pure Python standard library, `os` only) writes exactly one word
— 8 characters — describing the boss, to `/output/entry.txt`.

## Why this word

> Arsonist

The boss who starts the fires, then gets praised for putting them out. It
is a real word a person would actually use about their boss, it rings true
(the create-the-crisis-then-solve-it pattern is a real boss habit), and it
is fresh — nobody's first word for a boss is "arsonist".

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same word, byte for byte, on every run.
